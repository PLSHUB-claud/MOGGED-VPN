# Análise Comparativa: MOGGED-VPN vs. Soluções Comerciais

| Critério | MOGGED-VPN | Mullvad VPN | ProtonVPN |
|---|---|---|---|
| **Modelo de Custos** | 100% Gratuito | Pago (€5/mês) | Freemium |
| **Foco de Uso** | Desbloqueio de Go Live / Discord RTC | Privacidade geral e anonimato | Privacidade geral |
| **Split-Tunneling Discord** | Dedicado e Automático (Subnets + Domínios) | Manual por executável | Manual por executável |
| **Protocolos Suportados** | OpenVPN (Wintun) & WireGuard | WireGuard & OpenVPN | WireGuard, OpenVPN, Stealth |
| **Infraestrutura de Servidores** | Rede Pública Descentralizada (VPN Gate) | Servidores Próprios Dedicados | Servidores Próprios Dedicados |
| **Proteção contra Vazamento DNS** | `block-outside-dns` no Windows WFP | Servidores DNS DoH próprios | DNS Seguro próprio com NetShield |
| **Kill Switch** | Regras dedicadas Windows Firewall | Firewall Integrado WFP | Firewall Integrado WFP |
| **Criptografia Local** | Windows DPAPI | Armazenamento seguro de sessão | Armazenamento de credenciais |
| **Telemetria** | Zero | Zero | Mínima / Opcional |
