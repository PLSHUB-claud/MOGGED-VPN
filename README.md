# MOGGED VPN

VPN simples que troca só o IP do Discord. Serve pra liberar o compartilhamento de tela (Go Live) sem afetar o resto da sua internet.

## Como funciona

- Só o tráfego do Discord passa pela VPN.
- O resto do PC continua usando sua conexão normal.
- Voz e vídeo continuam funcionando.
- Não mexe nas configurações de rede do Windows.

## Como usar
1. Baixe o moggerVpn.exe
2. Execute como administrador.
